# 강의 가이드 — 하루의 첫 브리핑 (90분 1회 / 50분 2회)

## 90분 1회
| 시간 | 내용 | 활동 |
|---|---|---|
| 0~10분 | 도입 — 2026년 11월 뉴스 한 줄, "왜 대단한가?" 질문 | 학생에게 소수 5개 말해 보기 |
| 10~25분 | 1단계 블록 | 대시보드 ①: 체 거르기를 모두 함께 → 25개 확인 / 1은 왜 소수가 아닌가 토론 |
| 25~40분 | 2단계 쓰임 | 대시보드 ②: 짝끼리 "곱하기 vs 쪼개기" 자릿수 3→5→7 비교, 서랍 10개 vs 11개 |
| 40~50분 | 3단계 드물어짐 | 개수 맞히기 게임(어림 없이 감으로) |
| 50~62분 | 4단계 어림 | 손계산: ln(100만) ≈ 13.8 → 72,382 / 그래프로 좋은 어림 확인 |
| 62~75분 | 5단계 약속 | 일기예보 ± 비유 → 약속 범위 550 손계산 → AI 판단 코너 ① |
| 75~85분 | 6단계 좋은 점 + 대결 | AI 판단 코너 ②(암호), 대결 네 문제를 반 전체 투표 후 판정 |
| 85~90분 | 정리 | 오늘의 한 줄 각자 써 보기 |

## 50분 2회
- 1회: 1~3단계 + 대시보드 ①②③
- 2회: 4~6단계 + 대결

## 자주 나오는 오해 (수업 중 짚을 곳)
1. "소수는 언젠가 없어진다" → 3단계, 끝없이 있다(유클리드)
2. "수조 개 확인했으면 증명이다" → 5단계 AI 판단 코너 ①
3. "리만 가설이 증명되면 암호가 뚫린다" → 6단계 AI 판단 코너 ②
4. "리만 가설 = 소수가 무한히 많다" → 5단계 확인 퀴즈

## 주의
- 5단계 "점 하나를 옮기면 10의 몇 제곱부터 깨진다"는 크기만 비교한 설명용 모형이다. 실제 수치로 소개하지 않는다.
- 2026년 소식은 기준 시점(2026-11-22)을 함께 말한다. 학계의 정식 인정 절차는 남아 있다.
