# 하루의 첫 브리핑 — 주판봇은 왜 리만 가설을 못 풀었나

처음 오신 분을 위한 연구실 해설입니다. 2026년 11월 "수학자와 AI(클로드)가 리만 가설을 증명했다"는 소식을 들고 주판봇이 뛰어 들어오고,
초파리 연구원이 "로봇 주제에 주판은 왜 들고 다니냐"고 놀립니다. 오후 브리핑을 맡은 조수 하루가 인턴 시아·모아의 질문에 답하며,
세기(확인)와 증명이 무엇이 다른지, 클로드와 수학자가 무엇을 했는지, 우리 일에 무엇이 바뀌는지 풀어 갑니다.

- 공개 주소: https://adminmrobo.github.io/riemann_hypothesis_lab/
- 2부: `part2.html` — 「주판봇의 증명 나무 — Lean은 증명을 어떻게 검사하나」 (주판봇이 브리핑)
- 글 · 안상선 ((주)M-Robo 대표) · 기준 시점 2026-11-23
