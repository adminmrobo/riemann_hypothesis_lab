# 하루의 첫 브리핑 — 리만 가설은 '약속'이다

처음 오신 분을 위한 연구실 해설입니다. 조수 하루가 인턴 시아·모아 앞에서 첫 브리핑을 합니다.
방청석의 X1~X3는 긴장한 하루를 걱정하고, 초파리 연구원과 주판봇이 돕고, 박사가 단계마다 정리합니다.

- 공개 주소(GitHub Pages를 켜면): https://adminmrobo.github.io/riemann_hypothesis_lab/
- 글 · 안상선 ((주)M-Robo 대표) · 기준 시점 2026-11-22

## 구성
| 파일 | 내용 |
|---|---|
| `index.html` | 목차 · 3줄 상자 · 등장인물 · 대시보드 모음 |

| `assets/rh.js` | 단계별 복습·실험 대시보드 (외부 라이브러리 없음) |

| `code/check_riemann.py` | 페이지 숫자 검산 — `python3 code/check_riemann.py` |
| `docs/` | 기획안 · 표지 그림 지시문 · 교수법 자가 채점 |

## 단계와 대시보드
| 단계 | 제목 | 대시보드 |
|---|---|---|
| 1 | 소수는 숫자의 레고 블록 | 블록 쪼개기 공방 — 체 거르기, 쪼개기 기계, 소수 감별 퀴즈 |
| 2 | 소수는 어디에 쓰이나 | 자물쇠·서랍·매미 실험실 — 곱하기 vs 쪼개기, 서랍 수 바꾸기 |
| 3 | 뒤로 갈수록 드물어진다 | 소수 세기 관측소 — 비율 곡선, 개수 맞히기 |
| 4 | 어림으로 맞혀 보기 | 어림 비교판 — 실제 vs 두 가지 어림 |
| 5 | 리만 가설 = 약속 | 약속 감시판 — 빗나감과 약속 범위, 가운데 줄 모형 |
| 6 | 약속이 지켜지면 좋은 점 | 약속 활용 센터 — 범위 계산기, 소수 간격, 자물쇠 계획기 |
| 대결 | 소수 개수 맞히기 | 시아(간단한 어림) vs 모아(좋은 어림), 주판봇 판정 |
